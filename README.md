# 鉄千

Minecraft統合版で遊べる、鉄をテーマにした対戦ゲーム用アドオンです。

管理者は専用コンパスから設定画面を開き、暗視やチームモードなどのゲーム設定を簡単に操作できます。

## 主な機能

- 管理用コンパスから設定画面を表示
- OPへ管理用コンパスを自動配布
- 暗視のオン・オフ設定
- チームモードのオン・オフ設定
- プレイヤーごとのチーム色設定
- 同じ色を選択したプレイヤーを同じチームとして管理
- 設定UIからゲーム開始処理を実行
- `/scriptevent`による予備の管理メニュー起動

## 対応環境

- Minecraft Bedrock Edition
- Minecraft統合版のScript API対応環境
- チートが有効なワールド
- ビヘイビアーパックを使用できるワールド

## 導入方法

1. 配布されている`.mcpack`ファイルをダウンロードします。
2. `.mcpack`ファイルを開き、Minecraftへインポートします。
3. 鉄千を使用するワールドの設定を開きます。
4. 「ビヘイビアーパック」から鉄千を有効化します。
5. 必要に応じて、実験機能やベータAPIを有効化します。
6. ワールドへ入ります。

古いバージョンを使用している場合は、古い鉄千パックを無効化してから最新版を有効化してください。

## 管理用コンパス

ワールドへ参加したOPには、管理用コンパスが配布されます。

管理用コンパスを手に持って使用すると、鉄千の設定画面が開きます。

通常のコンパスでも、OPが使用した場合は設定画面を開ける構成になっています。

## 基本設定

管理画面では、次の設定を変更できます。

### 暗視

暗視をオンにすると、ゲーム開始時にワールド内のプレイヤーへ暗視効果を付与します。

オフにすると、暗視効果を解除します。

### チームモード

チームモードをオンにすると、次の画面でプレイヤーごとのチーム色を設定できます。

チームモードをオフにすると、個人戦としてゲーム開始処理へ進みます。

## チーム設定

チームモードをオンにした場合、オンライン中の各プレイヤーへチーム色を設定できます。

選択できる色は次のとおりです。

- 白
- オレンジ
- 赤紫
- 空色
- 黄色
- 黄緑
- 青
- 赤
- 緑
- 紫

同じ色を選択したプレイヤーは、同じチームとして扱われます。

## 予備の管理コマンド

コンパスから設定画面を開けない場合は、次のコマンドを使用できます。

```mcfunction
/scriptevent tessen:menu
``
